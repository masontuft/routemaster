# routemaster
Web app for service companies that builds daily routes and pairs well with Sprinkler Messenger.

## Working with AI agents

- `AGENTS.md` holds the rules every AI agent follows in this repo. `CLAUDE.md` points to it.
- `skills/` holds the shared skills that `AGENTS.md` refers to. Each folder has one `SKILL.md`.
- `ledger/` holds the AI-to-AI session logs described in the `ai-ledger-handoff` skill.
