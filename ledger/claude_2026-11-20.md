# Claude, 2026-11-20

## Tests moved to a tests/ folder (issue 70)

- **Changed:** all `*.test.js` files moved from `src/` to a top-level `tests/` that mirrors `src/` (73 `git mv` renames). `src/test/db.js` is now `tests/helpers/db.js`; `src/import/fixtures/tiny.xlsx` is now `tests/fixtures/tiny.xlsx` (the `.gitignore` exception follows it). Relative imports rewritten by script; nine tests that read views, routes, migrations, docs or the fixture by path were repointed. `scripts/generate-erd.js` imports the new helper. Docs: `AGENTS.md` Testing, `docs/qa/*`, `docs/process/customer-lifecycle.md`, the `src/db/erd.js` comment and the regenerated `database-erd.md`, a note in ADR 0011, `CHANGELOG.md`. Branch `refactor/move-tests-to-tests-folder`, off `main`.
- **Why:** issue 70: with every test in `src/`, the repo was hard to navigate.
- **Decisions:** (1) A mirrored layout, not a flat folder, because `auth.test.js` and `import.test.js` would collide with their siblings, and a test stays easy to find from its source file. (2) Named `tests/`, not `test/`, since `node --test` runs every `.js` file in a directory named `test` as a test. (3) The `test` script is unchanged: `node --test` finds `*.test.js` anywhere. (4) Older ADRs and ledger entries keep their old `src/...test.js` paths; ADR 0011 says to read them as the same path under `tests/`.
- **Open / next:** No schema change, so the FigJam board needs no update. Verified: `pnpm test` 692 of 692 (693 before the move, which counted `src/test/db.js` as a test) and `pnpm lint` clean, against the local `routemaster_test` database. CI is not run yet.
