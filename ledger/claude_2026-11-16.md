## Put customer review of unusual names on the roadmap

- **Changed:** `docs/product/roadmap.md` (two new bullets, after "Property type": customer review of unusual names, and fixing a flagged name in the import preview), this file. Branch `docs/roadmap-customer-name-review`, from `main` at 20d28c5. Docs only; no code, schema or tests.
- **Why:** While planning the name normalization rules, Mason asked whether the customer could review unusual names too. The plan makes that a second, later change, and Mason asked for it to go on the roadmap.
- **Decisions:** Confirm-or-suggest, not free editing: a link is a bearer token, so a correction waits for staff approval. Staff review at import stays. Name decisions agreed: a joint name stays one customer and is handled automatically, and Jr/Sr stay in the match key. A flagged import row (rental, business, "last, first", one word, digits) is skipped until the owner fixes the sheet and runs the import again (option A, chosen over importing it marked, or fixing it in the preview). Fixing in the preview went on the roadmap as an option: sheet rows have no stable id, so a fix would need a saved list matched to rows another way. Corrected the first bullet, which listed joint names as flagged.
- **Open / next:** The name normalization plan (`normalizePersonName`, `classifyName`, backfill script, import preview reasons, ADR) is approved in outline but not started. `docs/handoff/next-steps.md` still says migrations 001 through 019; the repo has 024.
