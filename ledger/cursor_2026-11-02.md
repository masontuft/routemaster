## 16:07 — Spreadsheet fetch and ExcelJS parse spike

- **Changed:** `src/import/googleSheet.js`, `src/import/xlsxRows.js`, `src/import/errors.js`, `src/import/limits.js`, their tests, `src/import/fixtures/tiny.xlsx`, `.gitignore` (exception for that fixture), `package.json` and `pnpm-lock.yaml` (`exceljs` 4.4.0), ADR 0009 (now Accepted), `docs/adr/README.md`, `ARCHITECTURE.md` (the spike open item is gone), data-flow, system overview, handoff, known limitations, test plan, dependency management, security assessment, threat model, `CHANGELOG.md`, this file.
- **Why:** GitHub issue 33. Mason approved the Google Sheet fetch spike and chose ExcelJS. The task was the spike, not the import screens.
- **Decisions:** The pasted link only supplies a sheet id. The request URL is always `https://docs.google.com/spreadsheets/d/{id}/export?format=xlsx`. Redirects are `manual`, at most two, and only back to that export path or a single-label `*.googleusercontent.com` `/export/` URL that still carries the same id and `format=xlsx`. `accounts.google.com` is treated as a private sheet and is not fetched. Other hosts are refused and the URL is not put in the error. Cookies are not stored. Caps are 5 MiB, 15 seconds, 40 sheets, 20,000 rows, and 64 columns. `multer` was not added because there is no route. `uuid` and `minimatch` overrides were not added. ExcelJS is pinned to 4.4.0. ADR 0009 is Accepted because Mason answered the open items and a public Google sample sheet downloaded through the module. Mason's customer sheet was not fetched. The PR says `Refs #33` because the issue's follow-up also asks to build the import, and that is not in this branch.
- **Open / next:** Owner route, then tab picker, column mapping, preview, and `import_batches` / `import_mappings`. Ask Mason before adding `multer`. Add a streaming read or an uncompressed-size cap before that route is exposed. ExcelJS expands the zip before the row cap. The live Google check is not in CI. Verified on Node 24.22.2: `pnpm lint` clean, `pnpm test` 156 of 156 against a local Postgres 16 throwaway database `routemaster_test` (created in this environment, not Mason's). Live module check of Google's public example spreadsheet: 5654 bytes, ZIP signature, one sheet "Class Data", 31 rows, 6 columns. Cell values were not printed.
