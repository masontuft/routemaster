# Roadmap

Post-course or optional. None is built.

- Dispatcher screens to create, send and revoke customer links, and to work the Needs Review queue.
- Send customer links in bulk through Sprinkler Messenger, the companion React Native app, using a deep link that opens the app and its mass-text feature on the dispatcher's phone. Viability is not confirmed: it depends on Messenger sending a different message to each customer and on iOS and carrier limits. Spec: [docs/integrations/sprinkler-messenger.md](../integrations/sprinkler-messenger.md).
- Multi-tenant support for multiple companies.
- Import of expenses, mileage and compressor schedule tabs.
- Export to `.xlsx`, then two-way spreadsheet sync via an admin button (needs Google OAuth or a service account).
- An instructor-hosted database as an optional target for server agents.
- Referral payout model for Rocky and Skyview, once the rule is understood.
- Technician logins, if wanted.
