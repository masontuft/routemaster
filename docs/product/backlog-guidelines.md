# Backlog Guidelines

Labels: `bug`, `enhancement`, `documentation`, `security`, `tech-debt`, `testing`, `accessibility`, `good-first-issue`, `help-wanted`; priority `high`, `medium`, `low`; status `blocked`, `ready`, `in-progress`.

Turn a defect into an issue with steps to reproduce, expected and actual behavior, and a test that would catch it. Turn an enhancement into an issue with the problem, a proposed solution, acceptance criteria and what is out of scope. Keep each issue small enough for one pull request.
