# Incident Response

A lightweight process for a one-person project; there is no on-call or paging.

1. **Triage:** what is broken, for whom, since when.
2. **Containment:** take the page or feature down, or roll back.
3. **Evidence:** keep logs and timestamps; no secrets in notes.
4. **Communication:** tell the instructor or affected users plainly.
5. **Recovery:** fix forward or roll back; verify with the health check.
6. **Retrospective:** write what happened and the fix in the ledger.
