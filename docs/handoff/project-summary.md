# Project Summary

Routemaster is Mason's CSE 340 final project (Option A): a server-rendered Express app for a sprinkler service business. In the code: authentication and sessions, CSRF (`csrf-sync`), service requests, magic and generic links, the staff dashboard, owner admin, reviews, contact and moderation, migrations 001 through 014, `pnpm seed`, and CI with a Postgres 16 service. Decisions: [ARCHITECTURE.md](../../ARCHITECTURE.md). Test strategy: [test-strategy](../qa/test-strategy.md). Security posture: [assessment](../security/security-assessment.md). Deployment is planned and unverified. Main risks: the sheet fetch route ([#33](https://github.com/masontuft/routemaster/issues/33)), instructor approval of an external database ([#19](https://github.com/masontuft/routemaster/issues/19), ADR 0007 stays Proposed), and the unbuilt import and daily-route work.
