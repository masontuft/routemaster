# Project Summary

Routemaster is Mason's CSE 340 final project (Option A): a server-rendered Express app for a sprinkler service business. In the code: authentication and sessions, CSRF (`csrf-sync`), service requests, magic and generic links, the staff dashboard, owner admin, reviews, contact and moderation, migrations 001 through 015, `pnpm seed`, and CI with a Postgres 16 service. Decisions: [ARCHITECTURE.md](../../ARCHITECTURE.md). Test strategy: [test-strategy](../qa/test-strategy.md). Security posture: [assessment](../security/security-assessment.md). Mason reported on 2026-11-02 that Supabase is set up, `pnpm migrate` has been run, and the Render web service is deployed with `/health` responding through the session pooler. Main risks: the sheet fetch route ([#33](https://github.com/masontuft/routemaster/issues/33)) and the unbuilt import and daily-route work. The instructor confirmed on 2026-11-02 that an external Supabase database satisfies the course ([ADR 0007](../adr/0007-persistence-postgres-on-supabase.md)).
